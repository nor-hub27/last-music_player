# Music Player (React)

A modern, fast, and sleek dark-mode music player built with React 19, TypeScript, and Vite.

## Features

- **Audio Playback**: Full playback control including Play, Pause, Previous, Next, Seek timeline, and current/total duration timing.
- **Local File & Folder Selection**:
  - Select individual audio files (`.mp3`, `.m4a`, `.flac`, `.ogg`, `.opus`, `.wav`, `.aac`, `.webm`).
  - Select entire music folders recursively using directory picker.
  - Drag and drop audio files directly into the player interface.
- **Built-in Demo Track**: One-click synthetic demo melody generator for instant audio testing without needing local audio files.
- **Queue & Playlists**: View loaded queue, switch tracks with a tap, track size indicator, Shuffle mode, and Repeat mode (All / Single / Off).
- **Debug Status Console**: Real-time action logging bar reflecting current audio engine state and user interactions.
- **Responsive Dark Theme**: Modern translucent card design matching the original aesthetic with glowing accent elements.

## Running Locally

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
