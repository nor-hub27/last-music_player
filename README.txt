Music Player - Android app project

1. Create a free account at github.com and make a new repository (any name, set it to Private).
2. Upload everything in this folder to it (drag the files and folders onto the page, including the .github folder).
3. Open the "Actions" tab, choose "Build APK" on the left, then press "Run workflow".
4. When it finishes (about 5 minutes) open the run and download "music-player-apk" at the bottom.
5. Unzip it, copy app-debug.apk to your phone, and open it. Android will ask you to allow installs from this source.

Updated: this version can add whole folders (computer browsers) and uses the sparkle image as the app icon.
When uploading to GitHub, make sure these all end up at the top level of the repository:
www, assets, .github, package.json, capacitor.config.json, make_icons.py
